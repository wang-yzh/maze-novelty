## Status

This version is a historical checkpoint. It should remain reproducible, but it is
not the active research direction anymore.

The `cyclic_replay` direction is deprecated for future experiments. It showed
that replay can increase reproducibility, but it also made the method slower and
started to collapse toward ordinary reinforcement learning. Future work should
not spend tuning effort on this branch unless a specific ablation needs it.

## Interpretation

- The cyclic family survived stronger traditional tabular baselines.
- `cyclic_three_phase` was viable, but did not beat simpler cyclic variants.
- `cyclic_replay` is not worth optimizing as a main branch because it does not
  solve the speed/reproducibility trade-off cleanly.
- The next active design is a larger cycle:

```text
explore -> operate -> explore -> operate -> replay
```

The intended meaning is:

- exploration creates diverse candidates,
- operation compresses candidates into faster working policies,
- replay is used sparingly at the end of a larger cycle to preserve reproducible
  successes rather than dominating every cycle.
