# v1.5.3 Multiseed Pretraining Benefit Result

## Purpose

`v1.5.2` added the longitudinal validation script and recommended one serious
multi-seed run before changing the model again.

This document records that run.

The question was deliberately strict:

```text
Does pretraining create a measurable target-adaptation benefit, after comparing
against scratch, shuffled-prior controls, and random-artifact controls?
```

## Run

Command:

```text
uv run python scripts/run_pretraining_benefit_longitudinal.py \
  --seeds 7,17,27 \
  --target-envs MiniGrid-FourRooms-v0,MiniGrid-MultiRoom-N2-S4-v0,MiniGrid-MultiRoom-N4-S5-v0 \
  --methods operate_replay_pretrain,cyclic_motif_fast_replay_pretrain,cyclic_subgoal_ecology_replay_pretrain \
  --pretrain-episodes 40 \
  --adapt-episodes 30 \
  --eval-every 10 \
  --eval-episodes 4 \
  --reuse-probe-episodes 6 \
  --output outputs/pretraining_benefit_longitudinal_v1_5_2_multiseed.csv \
  --points-output outputs/pretraining_benefit_longitudinal_v1_5_2_multiseed_points.csv \
  --summary-output outputs/pretraining_benefit_longitudinal_v1_5_2_multiseed_summary.csv
```

## Headline Result

The current answer is:

```text
No robust pretraining benefit was validated.
```

More precisely:

- hard MultiRoom targets produced zero task score for every tested method and
  control;
- FourRooms produced nonzero outcomes, but scratch had the strongest mean AUC;
- some pretrained conditions had positive final score because scratch final was
  zero, but their mean adaptation AUC was lower than scratch;
- shuffled-prior and random-artifact controls sometimes matched or exceeded
  real target reuse on structural proxy metrics.

This means the project can no longer treat region transitions, executed priors,
or goal-proximity proxy movement as evidence of transfer benefit by themselves.

## FourRooms Result

FourRooms is useful as a calibration target because success is possible under
the small local budget. It does not support a strong pretraining claim.

| Condition | Source | Nonzero Final | AUC | AUC Lift | Final |
| --- | --- | ---: | ---: | ---: | ---: |
| `scratch` | `scratch` | 0 / 3 | 0.2047 | 0.0000 | 0.0000 |
| `pretrained_agent` | `cyclic_motif_fast_replay_pretrain` | 2 / 3 | 0.0859 | -0.1188 | 0.2753 |
| `pretrained_agent` | `cyclic_subgoal_ecology_replay_pretrain` | 0 / 3 | 0.1246 | -0.0801 | 0.0000 |
| `pretrained_agent` | `operate_replay_pretrain` | 1 / 3 | 0.0242 | -0.1804 | 0.1454 |
| `pretrained_agent` | `random_artifact_control` | 1 / 3 | 0.1320 | -0.0727 | 0.1435 |
| `target_reuse` | `cyclic_motif_fast_replay_pretrain` | 1 / 3 | 0.0642 | -0.1405 | 0.1451 |
| `target_reuse` | `cyclic_subgoal_ecology_replay_pretrain` | 0 / 3 | 0.1715 | -0.0331 | 0.0000 |
| `target_reuse` | `operate_replay_pretrain` | 1 / 3 | 0.0769 | -0.1278 | 0.1729 |
| `target_reuse` | `random_artifact_control` | 1 / 3 | 0.0829 | -0.1218 | 0.1439 |

Interpretation:

```text
Final score lift alone is misleading here.
```

Several pretrained or reuse conditions end with nonzero final scores while
scratch final is zero, but scratch still has the best mean adaptation AUC. That
suggests scratch found transient success earlier in the evaluation curve, while
the tested pretraining paths did not convert into a stronger adaptation process.

The negative controls are also not cleanly beaten. `random_artifact_control`
reaches nonzero final score in one seed, and shuffled-prior controls can produce
high structural activity.

## Hard MultiRoom Result

Both hard targets were all-zero at the task level.

| Target | Condition Set | Final Score | AUC | AUC Lift |
| --- | --- | ---: | ---: | ---: |
| `MiniGrid-MultiRoom-N2-S4-v0` | all methods and controls | 0.0000 | 0.0000 | 0.0000 |
| `MiniGrid-MultiRoom-N4-S5-v0` | all methods and controls | 0.0000 | 0.0000 | 0.0000 |

Interpretation:

```text
The hard targets are currently too sparse for this validation budget.
```

They remain useful as stress tests, but they cannot distinguish methods by
target-task success yet.

adaptation.

## What This Invalidates

This result invalidates a weak claim:

```text
Pretraining is useful because it creates more region transitions or more prior
executions.
```

That claim is no longer acceptable. Similar structural activity can appear under
shuffled and random controls.

This result does not invalidate the long-term direction. It says the current
behavior-prior pipeline has not yet converted pretraining history into reliable
target-task advantage.

## Current Research Answer

The honest answer is now:

```text
Pretraining changes target-side behavior.
Pretraining has not yet been shown to improve target adaptation.
Current structural metrics are diagnostic, not proof.
```

A stronger future claim must satisfy:

```text
positive adaptation_auc_lift
AND positive final or earlier first success
AND better than random artifact control
AND better than shuffled prior control
AND stable across multiple seeds
```

## Decision

Do not add another large cycle variant yet.

The next useful work is to make the validation ladder more informative:

1. Add positive-control targets where transfer should be possible.
2. Add intermediate tasks between FourRooms and MultiRoom all-zero regimes.
3. Separate "pretraining changed exploration" from "pretraining improved
   adaptation."
4. Treat region transitions and prior executions as mechanistic diagnostics
   until they predict task-level success.

## Recommended Next Step

Build a calibrated transfer task ladder:

```text
source-like task
near-transfer task
medium-transfer task
hard sparse task
```

The ladder should include at least one target where scratch is not already the
strongest AUC baseline, but where success is still common enough to measure.

Until such a target exists, model optimization will keep confusing three
different problems:

```text
no effect
real but non-goal-directed structure
real transfer benefit
```
