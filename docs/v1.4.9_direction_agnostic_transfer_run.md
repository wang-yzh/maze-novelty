# v1.4.9 Direction-Agnostic Transfer Run

## Purpose

`v1.4.8` showed in a one-seed smoke that `direction_agnostic` matching strongly
increased prior matching and execution counts.

This run asks the next question:

```text
Does that signal survive a modest 3-seed run on the main transfer ladder?
```

The purpose is still not to claim final transfer.
The purpose is to decide whether `direction_agnostic` should become the default
research setting for the next stage.

## Command

```bash
uv run python scripts/run_pretraining_transfer_diagnostic.py \
  --seeds 7,17,27 \
  --target-envs MiniGrid-MultiRoom-N2-S4-v0,MiniGrid-MultiRoom-N4-S5-v0 \
  --methods operate_replay_pretrain,cyclic_motif_fast_replay_pretrain,cyclic_subgoal_ecology_replay_pretrain \
  --pretrain-episodes 40 \
  --adapt-episodes 30 \
  --eval-every 10 \
  --eval-episodes 4 \
  --include-target-reuse \
  --reuse-match-modes direction_agnostic \
  --output outputs/pretraining_match_ablation_v1.csv \
  --summary-output outputs/pretraining_match_ablation_v1_summary.csv
```

## Interpretation

This is a good, honest intermediate result.

What it means:

```text
direction_agnostic matching does not solve transfer,
but it consistently activates more reusable target-side structure.
```

The 3-seed signal is clearer than the earlier smoke because it preserves the
role split between methods:

- `cyclic_motif_fast_replay`:
  strongest reusable-fragment density on `N2-S4`;
- `operate_replay`:
  strongest transition-driving execution on `N4-S5`;
- `cyclic_subgoal_ecology_replay`:
  strongest mobility among the `N2-S4` reuse families and strong harder-target
  execution volume.

That means the project now has a more stable structural picture:

```text
motif_fast     = strongest short-fragment reuse candidate
operate_replay = strongest transition-driving executor
subgoal_ecology = strongest sparse-memory structural reservoir
```

## Decision

Based on this run:

```text
direction_agnostic should be promoted from ablation setting
to the default research setting for target-side reuse work
```

Not because it wins on final score, but because it gives the cleanest and most
stable mechanism activation under the current budget.

## What This Does Not Solve

This run still leaves the core unsolved problem unchanged:

```text
activated reusable structure still does not compose into target success
```

So the bottleneck is no longer matching.

The bottleneck is now more clearly:

```text
execution semantics and composition
```

## Recommended Next Step

The next version should stop modifying matching and start modifying execution.

Recommended next target:

```text
bounded option execution with abort
```

Minimal version:

1. start from the current `direction_agnostic` setting;
2. execute a prior as a short option;
3. abort execution if signature compatibility collapses;
4. compare against the current open-loop trace execution.

That is now the highest-value next experiment.
