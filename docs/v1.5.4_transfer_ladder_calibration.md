# v1.5.4 Transfer Ladder Calibration

## Purpose

The multiseed pretraining-benefit run showed that the current targets are poorly
calibrated:

```text
FourRooms: measurable, but scratch/control-confounded.
MultiRoom: all-zero under the tested budget.
```

This version adds a transfer ladder calibration layer. The goal is not to prove
the model yet. The goal is to find targets where proof is possible.

## New Script

```text
scripts/run_transfer_ladder_calibration.py
```

The script runs the existing longitudinal validator, then classifies each target
environment into a research tier.

Default candidate set:

```text
MiniGrid-FourRooms-v0
MiniGrid-Dynamic-Obstacles-8x8-v0
MiniGrid-Dynamic-Obstacles-16x16-v0
MiniGrid-SimpleCrossingS9N1-v0
MiniGrid-SimpleCrossingS9N2-v0
MiniGrid-MultiRoom-N2-S4-v0
MiniGrid-MultiRoom-N4-S5-v0
```

These candidates stay inside the current navigation-only MiniGrid action set.
DoorKey, KeyCorridor, Unlock, and Fetch-style tasks still need an explicit
action-space upgrade before they can be treated fairly.

## Classification Tiers

| Tier | Meaning |
| --- | --- |
| `source_like_regression` | Same as the source environment; useful for regression, not transfer claims. |
| `all_zero_hard` | No method or control produced task-level signal under the budget. |
| `scratch_dominated` | Scratch already has high AUC and pretraining does not clear the lift margin. |
| `control_confounded` | Negative controls match or exceed the best real pretraining signal. |
| `unstable_transfer_signal` | Mean real-pretraining signal clears margins, but positive lift is not stable across seeds. |
| `candidate_transfer_signal` | Real pretraining clears scratch lift and negative-control margins. |
| `measurable_candidate` | Nonzero task signal exists, but there is no clean transfer claim yet. |

Default decision thresholds:

```text
min_signal_auc = 0.01
easy_scratch_auc = 0.18
lift_margin = 0.03
control_margin = 0.02
```

## Intended Use

Quick candidate sweep:

```text
uv run python scripts/run_transfer_ladder_calibration.py \
  --seeds 7 \
  --pretrain-episodes 24 \
  --adapt-episodes 18 \
  --eval-every 6 \
  --eval-episodes 3 \
  --reuse-probe-episodes 5
```

Classify an existing longitudinal summary without rerunning training:

```text
uv run python scripts/run_transfer_ladder_calibration.py \
  --no-run-validation \
  --summary-input outputs/pretraining_benefit_longitudinal_v1_5_2_multiseed_summary.csv
```

## Why This Matters

The project needs an evaluation ladder with at least one middle zone:

```text
not solved by scratch immediately
not all-zero for every method
not explained by random or shuffled controls
```

Without that middle zone, every model change is hard to interpret:

```text
FourRooms can over-reward noise and scratch luck.
MultiRoom can hide every difference behind sparse failure.
```

The ladder script makes this an explicit screening step before more algorithmic
work.

## Current Decision

Before changing the behavior-prior representation again, run a candidate ladder
sweep and promote only targets that are at least `measurable_candidate`.

The best next benchmark target is not necessarily the hardest target. It is the
target that can distinguish:

```text
real transfer benefit
control-induced movement
scratch exploration luck
complete sparse-reward failure
```
