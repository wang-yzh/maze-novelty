# Archive Guide

This directory is the archive landing page for the Maze Novelty repository.

The repository is closed as an active research line, but it is still useful as
an organized reference for earlier findings and mechanism prototypes.

## Primary Entry Points

Start with these files if you are reopening the repo after a break:

- `../project_closure_2026-04-20.md`
  Final closure note and the recommended direction for the next project.
- `../pretraining_transfer_framework.md`
  The central framing for the later transfer-oriented work.
- `../version_history.md`
  Ordered summary of important checkpoints and lessons.
- `../../README.md`
  Top-level repo overview, quick start, and quality-check commands.

## Historical Material

Most historical writeups remain in `../` with explicit versioned names such as
`v1.4.7_behavior_prior_transfer.md` or `v1.5.5_transfer_ladder_sweep_result.md`.
They stay at the docs root so existing citations and README references keep
working.

Supplemental legacy archive material that is already parked here:

- `v0.4_explore_operate_report.md`

## Suggested Reading Order

Use this order when you want the shortest path from archive status to past
results:

1. `../project_closure_2026-04-20.md`
2. `../version_history.md`
3. `../pretraining_transfer_framework.md`
4. the specific `v*.md` writeup related to the mechanism you care about
