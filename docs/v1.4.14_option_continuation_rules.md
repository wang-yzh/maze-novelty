# v1.4.14 Option Continuation Rules

## Goal

`v1.4.13` added a motif-fragment executor, but it was still mostly a prior
selection change.

This step adds execution-time continuation rules:

```text
when a prior starts executing, decide whether the option is still alive after
each step
```

This is a stronger mechanism than only asking which prior to start.

## New Rules

Three continuation modes now exist.

| Rule | Meaning | Intended Use |
| --- | --- | --- |
| `signature` | old behavior; abort only when expected state signatures mismatch beyond tolerance | default baseline |
| `motif_consistency` | abort on signature mismatch or failed forward movement | short motif fragments |
| `progress_guard` | tolerate signature mismatch while coarse progress evidence remains alive; abort on failed forward movement | subgoal/ecology priors |

Important implementation detail:

```text
only failed forward movement counts as stall
```

Turning left or right in MiniGrid leaves position unchanged by design. Treating
turns as stalls over-aborts valid navigation motifs.

## Runner Changes

The diagnostic runner now accepts:

```bash
--reuse-continuation-rule signature|motif_consistency|progress_guard
--reuse-stall-tolerance N
```

It also records:

- `target_reuse_continuation_rule`
- `target_reuse_stall_tolerance`
- `target_reuse_mismatched_prior_steps`
- `target_reuse_stalled_prior_steps`

One bookkeeping bug was fixed: branch-specific rows now record the actual
resolved reuse config, not only the raw CLI defaults.

## Branch-Specific Preset

The experimental branch-specific preset now maps methods as follows.

| Method | Execution Mode | Continuation Rule |
| --- | --- | --- |
| `operate_replay_pretrain` | `default`, open-loop | `signature` |
| `cyclic_motif_fast_replay_pretrain` | `motif_fragments` | `motif_consistency` |
| `cyclic_subgoal_ecology_replay_pretrain` | `default` | `progress_guard` |

This is still experimental. The main baseline remains:

```text
uniform direction_agnostic + soft_abort
```

## Quick Result

Comparison is against the previous `v1.4.13` branch-specific smoke.

### `cyclic_motif_fast_replay`

| Target | Setting | Exec Steps | Aborts | Aborted Steps | Exec Subgoal | Exec Transitions | Exec Mobility |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `N2-S4` | `v1.4.13 motif_fragments` | `498` | `11` | `27` | `0.0550` | `3.25` | `0.1123` |
| `N2-S4` | `motif_consistency` | `465` | `26` | `105` | `0.0549` | `3.00` | `0.1416` |
| `N4-S5` | `v1.4.13 motif_fragments` | `415` | `61` | `116` | `0.0804` | `9.00` | `0.1738` |
| `N4-S5` | `motif_consistency` | `344` | `97` | `235` | `0.0815` | `10.25` | `0.1855` |

Interpretation:

```text
motif_consistency executes less volume but sometimes improves structural
quality, especially on N4-S5
```

It is not a promotion yet. It is a sharper tool.

### `cyclic_subgoal_ecology_replay`

| Target | Setting | Exec Steps | Aborts | Aborted Steps | Exec Subgoal | Exec Transitions | Exec Mobility |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `N2-S4` | `v1.4.13 soft abort` | `190` | `3` | `12` | `0.0563` | `6.00` | `0.1543` |
| `N2-S4` | `progress_guard` | `190` | `3` | `12` | `0.0563` | `6.00` | `0.1543` |
| `N4-S5` | `v1.4.13 soft abort` | `372` | `58` | `147` | `0.1006` | `12.00` | `0.1455` |
| `N4-S5` | `progress_guard` | `386` | `30` | `77` | `0.1003` | `9.25` | `0.1582` |

Interpretation:

```text
progress_guard reduces abort pressure and preserves more execution, but it can
trade room-transition quality for mobility
```

This suggests it is a candidate for ecology-style priors, but it needs more
seeds before promotion.

## Decision

Keep this step as an experimental executor layer.

Do not yet promote branch-specific presets.

The main value is architectural:

```text
prior reuse now has a place to express option-level survival rules
```

This gives the project a better path for pretraining transfer than simply
adding more cycle variants.
