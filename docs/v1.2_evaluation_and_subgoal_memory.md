# v1.2 Evaluation And Subgoal Memory

## Goal

This version stabilizes the experimental foundation before adding more algorithm variants.

The main change is to separate task performance from diagnostic evidence:

- `primary_score`: task-facing score. It follows the existing MiniGrid evaluation score and is the only score that should be used for winner claims.
- `diagnostic_score`: failure-analysis score. It summarizes subgoal progress, region transitions, new regions, and mobility. It explains failures but does not prove task success.

This avoids the failure mode seen in the market sandbox where a mixed score could look stable while the real profit metric was poor.

## New Diagnostic Fields

The MiniGrid metrics output now includes:

- `primary_score`
- `diagnostic_score`
- `subgoal_score`
- `best_subgoal_score`
- `region_transition_count`
- `best_region_transition_count`
- `new_region_count`
- `best_new_region_count`
- `revisit_ratio`
- `mobility`
- `max_distance_from_start`

When multiple evaluated agents have the same `primary_score`, reporting uses `diagnostic_score` as a tie-breaker. This does not change primary task ranking when one agent is actually better at the task, but it makes all-failure runs easier to inspect.

## Subgoal Memory

`ScoredMotifBank` now supports subgoal motifs from failed rollouts.

Motif classes:

- `confirmed_fast`: successful rollout within the fast threshold.
- `confirmed_medium`: successful rollout within the medium threshold.
- `candidate_progress`: non-success rollout with enough old progress signal.
- `candidate_mobility`: non-success rollout with high mobility.
- `subgoal_transition`: non-success rollout with useful diagnostic subgoal score and region transitions.
- `subgoal_exploration`: non-success rollout with useful diagnostic subgoal score and new-region discovery.

Confirmed motifs still receive the strongest replay reward. Subgoal motifs receive a lower reward than confirmed motifs but higher reward than generic candidates.

## New Method

`cyclic_subgoal_ecology_replay` is the first complex-task candidate built on this foundation.

Cycle:

```text
open_explore -> niche_sort -> operate -> stress_gate -> bottleneck -> subgoal_replay
```

Purpose by phase:

- `open_explore`: high novelty and subgoal discovery.
- `niche_sort`: preserve different useful failure modes instead of only full successes.
- `operate`: compress behavior with lower exploration and mild revisit/turn penalties.
- `stress_gate`: allow either successful policies or high-diagnostic failed policies to survive.
- `bottleneck`: rebuild the population from stress survivors, niche elites, and hall-of-fame agents.
- `subgoal_replay`: reinforce confirmed and subgoal motifs.

## Smoke Test

Command:

```bash
uv run python src/minigrid_train.py \
  --env-id MiniGrid-MultiRoom-N4-S5-v0 \
  --seed 7 \
  --output-dir outputs/v1_2_smoke_multiroom \
  --generations 6 \
  --population 4 \
  --episodes-per-agent 1 \
  --eval-episodes 3 \
  --eval-every 3 \
  --state-encoder geometry \
  --method-time-limit-seconds 25 \
  --methods cyclic_operate_replay,cyclic_subgoal_ecology_replay
```

Result:

- Both methods had `primary_score=0.0` on the tiny smoke test.
- `cyclic_subgoal_ecology_replay` filled its motif bank immediately with subgoal transition motifs.
- The final row recorded `motif_count=20`, `candidate_motif_count=20`, `subgoal_motif_count=10`, and `transition_motif_count=10`.

Interpretation:

The new method is not yet proven stronger. The important result is that complex-task failures can now produce structured, replayable memory instead of leaving the replay system empty.

## Next Experiment

Run a real MultiRoom diagnostic benchmark with 3 seeds and 100 seconds per method:

```text
cyclic_operate_replay
cyclic_motif_fast_replay
cyclic_subgoal_ecology_replay
```

Compare:

- primary success and average steps
- diagnostic score
- subgoal motif fill time
- replay improvement delta
- region transitions and new regions

The next decision should be based on whether subgoal memory improves diagnostic progress first, and only then whether it converts into primary success.
