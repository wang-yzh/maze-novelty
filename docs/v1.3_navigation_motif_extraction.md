# v1.3 Navigation Motif Extraction

## Purpose

This version implements the first diagnostic layer from `theory_structural_novelty_and_options.md`.

It does not change training. It only asks:

```text
Can we detect navigation-like behavior fragments from positions/actions alone?
```

This keeps the next step grounded. If the system cannot identify reusable movement structure, adding another replay phase is premature.

## Added Module

`src/navigation_motifs.py` extracts short executable fragments from a rollout.

Input:

```text
rollout.positions
rollout.actions
```

It intentionally avoids MiniGrid object-specific observations. The first version should remain trajectory-only so the idea can transfer to other domains.

Motif classes:

| Motif | Meaning |
| --- | --- |
| `forward_run` | repeated forward movement with low collision proxy |
| `wall_follow_left` | blocked forward action followed by left turn and forward movement |
| `wall_follow_right` | blocked forward action followed by right turn and forward movement |
| `region_transition` | short segment around a coarse region boundary crossing |
| `unstuck` | segment where revisit ratio drops or mobility improves |

Each motif records:

- start and end index;
- action sequence;
- position sequence;
- quality score;
- mobility;
- region transition count;
- revisit reduction;
- collision proxy rate.

## Diagnostic Script

`scripts/run_navigation_motif_diagnostics.py` runs simple policies and extracts navigation motifs.

Command:

```bash
uv run python scripts/run_navigation_motif_diagnostics.py \
  --env-id MiniGrid-MultiRoom-N4-S5-v0 \
  --seed 7 \
  --episodes 12 \
  --max-steps 256 \
  --state-encoder geometry \
  --output outputs/v1_3_navigation_motif_diag_seed7.csv
```

## Interpretation

The extractor passes the first sanity check:

- wall-following policies generate far more navigation motifs than random policies;
- left and right wall-following are separated correctly;
- wall-following motifs have higher average quality;
- transitions and mobility align with the motif counts.

The random policies still generate nonzero wall-follow-like motifs. This is expected because short random action sequences sometimes match the local pattern. The next filter should use recurrence, quality thresholds, and cross-rollout survival to remove accidental fragments.
