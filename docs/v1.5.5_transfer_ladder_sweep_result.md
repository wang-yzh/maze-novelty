# v1.5.5 Transfer Ladder Sweep Result

## Purpose

This run used the transfer ladder calibrator to search for intermediate targets:

```text
not source-only regression
not all-zero hard failure
not dominated by scratch
not explained by random or shuffled controls
```

The goal was target selection, not model optimization.

uv run python scripts/run_transfer_ladder_calibration.py \

## Classifier Correction

The first classifier version promoted a target to `candidate_transfer_signal`
when mean real-pretraining AUC cleared scratch and negative-control margins.

This was too permissive. In this sweep, the apparent Dynamic-Obstacles signals
were positive in only one of two seeds.

The classifier was updated to add:

```text
unstable_transfer_signal
```

Meaning:

```text
mean clears margins, but positive lift is not stable across seeds
```

This keeps the ladder aligned with the project's current evidence standard.

## Interpretation

The sweep found no target that justifies a clean transfer-benefit claim.

It did find a useful next focus:

```text
Dynamic-Obstacles is the best candidate family for follow-up.
```

Why:

- scratch stayed at zero;
- random and shuffled controls stayed at zero on AUC;
- real pretraining produced nonzero AUC;
- the signal is not yet stable across seeds.

This is exactly the kind of middle zone the project needed, but it must be
retested before it becomes a benchmark.

## Decision

Do not optimize the model on SimpleCrossing yet. It is currently too
control-confounded.

Do not use MultiRoom as the main feedback loop yet. It is still all-zero under
this budget.

Promote Dynamic-Obstacles to the next confirmation run:

```text
MiniGrid-Dynamic-Obstacles-8x8-v0
MiniGrid-Dynamic-Obstacles-16x16-v0
```

Recommended confirmation protocol:

```text
seeds = 7,17,27,37
pretrain_episodes = 32
adapt_episodes = 24
eval_every = 6
eval_episodes = 4
reuse_probe_episodes = 6
methods = operate_replay_pretrain,
          cyclic_motif_fast_replay_pretrain
```

The confirmation question should be:

```text
Does the Dynamic-Obstacles signal remain positive in most seeds,
and does it stay above random and shuffled controls?
```

Only after that should Dynamic-Obstacles become a primary transfer benchmark.
