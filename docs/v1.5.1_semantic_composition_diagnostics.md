# v1.5.1 Semantic Composition Diagnostics

## Purpose

`v1.5.0` introduced `semantic_intents`. It improved local behavior execution:

```text
more completed priors
fewer aborts
more mobility
more region transitions
```

But final transfer scores stayed zero. That means the next question is no
longer whether semantic priors can execute. The question is whether they create
state changes that can compose into task progress.

This version adds composition diagnostics.

## New Metrics

Each prior execution now records a composition outcome when it ends, whether by:

- completion;
- abort;
- episode truncation.

The recorded outcome compares the prior start state against the prior end state.

Aggregate CSV fields:

```text
target_reuse_composition_outcome_count
target_reuse_composition_region_change_count
target_reuse_composition_goal_visible_end_count
target_reuse_composition_goal_visibility_gain_count
target_reuse_composition_avg_displacement
target_reuse_composition_max_displacement
target_reuse_composition_avg_signature_progress_delta
```

The existing `target_reuse_prior_kind_stats_json` also includes per-kind
composition fields:

```text
composition_outcomes
region_changes
goal_visible_ends
goal_visibility_gains
avg_displacement
max_displacement
avg_signature_progress_delta
```

## Signature Progress Delta

This is a lightweight local diagnostic, not a task-success score.

It combines:

- whether the goal is visible;
- local topology openness;
- whether the front cell is passable.

It is meant to answer:

```text
Did this prior end in a locally more promising state signature?
```

It does not claim that the agent is closer to the global goal.

it may be creating movement without useful orientation.

## Interpretation

The bottleneck moved again:

```text
v1.4.x: priors often could not execute cleanly
v1.5.0: semantic priors execute cleanly and move
v1.5.1: movement still rarely creates goal visibility or solved episodes
```

The important negative result:

```text
goal_visibility_gain = 0 for every target-reuse method in this smoke run
```

So semantic priors are currently better at local locomotion and room crossing
than at producing target-directed discovery.

## Decision

Keep `semantic_intents` experimental.

The next useful improvement should not be another continuation guard. It should
make semantic priors goal- or doorway-aware.

Recommended next candidates:

1. Add a doorway/bottleneck descriptor to `StateSignature` or to prior outcomes.
2. Add post-prior credit shaping when a prior causes a region change or goal
   visibility gain.
3. Split `unstuck` into `escape_loop` versus `random_reorientation`; current
   `unstuck` is too broad.
4. Make `region_transition` choose actions based on recent region boundary
   direction, not only local passability.
