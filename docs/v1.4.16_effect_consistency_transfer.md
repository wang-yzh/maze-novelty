# v1.4.16 Effect Consistency Transfer

## Goal

`v1.4.15` showed that `cyclic_motif_fast_replay` had many first-step signature
mismatches, especially on `MiniGrid-MultiRoom-N4-S5-v0`.

The next hypothesis was:

```text
some signature mismatches are not true action failures;
the local observation can drift while the movement effect is still useful
```

This step adds movement-effect descriptors to priors and exposes an
effect-aware continuation mode.

## Added Descriptor

Each `BehaviorPrior` can now carry:

```text
effect_trace
```

Effects are coarse action outcomes:

| Effect | Meaning |
| --- | --- |
| `turn_left` | left turn action |
| `turn_right` | right turn action |
| `forward_move` | forward action changed position |
| `forward_blocked` | forward action did not change position |

The descriptor is produced from target probe rollouts and stored with motif and
fallback trace priors.

## Added Matching / Continuation

New reuse setting:

```text
effect_match_mode = none | first_step
```

`first_step` checks whether the first action effect is obviously compatible
with the current local signature. In this smoke, this filter did not materially
change results, which suggests it mostly overlaps with the existing local
signature match.

New continuation rule:

```text
effect_consistency
```

This rule still records signature mismatch, but it aborts based on movement
effect mismatch rather than local signature mismatch.

Branch-specific preset now maps:

```text
cyclic_motif_fast_replay_pretrain:
  execution_mode = motif_fragments
  continuation_rule = effect_consistency
  effect_match_mode = first_step
```

## New Metrics

The diagnostic output now includes:

- `target_reuse_effect_described_item_count`
- `target_reuse_first_step_effect_mismatch_count`
- `target_reuse_effect_mismatched_prior_steps`
- `target_reuse_effect_abort_count`

These separate:

```text
signature mismatch:
  local observation differs from expected signature

effect mismatch:
  the action did not do the expected coarse thing
```

## Quick Result

Comparison is against `v1.4.15` prior lifecycle diagnostics.

### `cyclic_motif_fast_replay`

| Target | Rule | Started | Completed | Aborted | First-Step Signature Mismatch | First-Step Effect Mismatch | Effect Aborts | Exec Steps | Exec Transitions | Exec Mobility |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `N2-S4` | `motif_consistency` | `96` | `64` | `30` | `12` | n/a | n/a | `465` | `3.00` | `0.1416` |
| `N2-S4` | `effect_consistency` | `89` | `88` | `0` | `8` | `0` | `0` | `530` | `3.75` | `0.1406` |
| `N4-S5` | `motif_consistency` | `113` | `8` | `103` | `67` | n/a | n/a | `344` | `10.25` | `0.1855` |
| `N4-S5` | `effect_consistency` | `95` | `68` | `26` | `70` | `0` | `26` | `444` | `6.75` | `0.1523` |

Interpretation:

```text
effect consistency confirms that many signature mismatches are not coarse
movement-effect failures
```

But it also introduces a tradeoff:

```text
more option completion,
less structural quality on N4-S5
```

So the result is not a promotion. It is a better diagnostic lens and a candidate
mechanism.

## What This Teaches Us

The previous interpretation was too blunt:

```text
first-step signature mismatch = bad launch
```

This smoke shows a more precise split:

```text
signature mismatch with effect match:
  descriptor is too brittle, or the transferred local morphology drifted

effect mismatch:
  the action itself failed at the coarse navigation level
```

For `cyclic_motif_fast_replay`, `effect_consistency` turns many aborts into
completed executions. That means some useful behavior survives below the
signature layer.

However, because structural quality dropped on `N4-S5`, pure effect consistency
is too permissive. It behaves partly like a safer open-loop replay, not yet like
a strong transfer policy.

## Decision

Keep:

- `effect_trace`
- effect mismatch diagnostics
- `effect_consistency` as an experimental continuation rule

Do not yet promote it as the main preset.

The strongest next idea is a hybrid gate:

```text
continue if movement effect matches,
but require periodic structural evidence such as region transition, novelty,
or subgoal progress
```

This would sit between:

```text
signature consistency:
  too brittle

effect consistency:
  too permissive
```
